# Orduva Ver-0.137 — Advanced Storefront Theme Editor

Adds tenant admin controls for per-section storefront colours:

- Global page colours
- Header colours
- Welcome card colours
- Product card, price, Add and More button colours
- Footer colours

Presets now populate the full theme item list and are highlighted more clearly. Tenants can then fine-tune individual hex colours and use per-row Preview buttons to jump the preview panel to the relevant storefront section.

## Required Supabase SQL

Run `SUPABASE_VER_0_137_STOREFRONT_THEME_JSON.sql` once before saving advanced theme settings.
