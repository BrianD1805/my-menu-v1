# Orduva Patch Ver-0.221A — Settings hover outline and softer mobile selection

## Summary
This patch removes the heavier green hover/open selection treatment from Tenant Settings accordions.

## Changes
- Main settings accordions now keep a white surface instead of turning green.
- Payment gateway accordions now keep a white surface instead of the darker green selected style.
- Desktop hover now uses a subtle orange outline/ring rather than a green filled background.
- Mobile no longer shows the darker green selected/hover panel colour.
- Plus icons now use neutral styling with an orange open state instead of green.

## SQL
No Supabase SQL required.

Ver: 0.221A
