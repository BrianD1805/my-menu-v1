# Orduva Ver-0.162 — tenant admin header and layout refinement pass

This build reduces repeated tenant/store identity text and makes the tenant admin feel lighter and less chunky.

## Changes

- Keeps the top Active store bar as the single main store identity area.
- Removes duplicate store name/store address pills from the secondary admin header.
- Removes duplicate store address wording from the session card.
- Removes the owner store-list card from the tenant admin hero area to keep client admin calmer.
- Reduces the tenant admin page title sizes, including the Home page Welcome back heading.
- Tightens header, hero, login, card, and checklist spacing.
- Keeps tenant admin soft grey backgrounds from Ver-0.160.

## Not changed

- Storefront UI.
- Public onboarding.
- Owner platform tools.
- Checklist saved progress logic.
- Logo/favicon upload or storage logic.
- Payment/free-trial logic.
- Supabase schema.
