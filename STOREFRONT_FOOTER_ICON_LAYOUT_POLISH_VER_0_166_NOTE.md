# Orduva Ver-0.166 — storefront footer icon layout polish

This patch updates the storefront footer icon area to a cleaner icon-only presentation.

## Included

- Increased the footer icon size by roughly 15%
- Improved the icon button styling for a more premium look
- Limited the footer icon area to a maximum of 8 icons
- Arranged icons in rows of 4, filling the first row before the second
- Kept the icon rows centred
- Removed the text content from the storefront footer icon panel
- Updated the admin settings helper text to match the new footer behaviour

## Not changed

- Storefront product card layout
- Checkout flow
- Wildcard routing
- Admin login flow
- Supabase schema
