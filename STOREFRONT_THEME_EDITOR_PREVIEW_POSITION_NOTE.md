# Orduva Ver-0.137B — Desktop Theme Preview Position Polish

This patch adjusts the advanced storefront theme editor preview column on desktop only.

## Change
- Moves the right-hand preview panel lower on desktop (`xl`) so it is visible opposite the colour controls while the user is working.
- Leaves mobile behaviour unchanged.

## Not changed
- Theme save logic
- Colour controls
- Suggested colours
- Storefront theme application
- Product cards
- Checkout/orders
- Customer accounts
- Push notifications
- Domain/onboarding logic
