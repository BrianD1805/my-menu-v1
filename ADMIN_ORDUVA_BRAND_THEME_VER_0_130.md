# Orduva Ver-0.130 Admin Brand Theme

Updated the tenant admin visual colour direction to use the Orduva root/platform palette:

- Obsidian: #0E0E10
- Orduva Orange: #FF6A3D
- Warm Apricot: #FFB168
- Cream: #FFF7F0
- Soft Stone: #F5F2EE
- Charcoal Text: #1F2328

Scope was visual admin branding only. Storefront tenant colour presets, product cards, add-to-cart animation, checkout, order persistence, customer accounts, push notifications, and domain/onboarding logic were not intentionally changed.
