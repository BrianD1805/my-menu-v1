# Orduva Ver-0.123 — Colour Preset Refresh

This patch refreshes the admin tenant theme presets.

## Changes
- Removed the ZimZa Express-specific red/gold palette from the general preset list.
- Added four clearly different reusable presets:
  - Premium Blue & Orange
  - Forest Green & Gold
  - Charcoal & Teal
  - Cream & Berry
- ZimZa Express colours remain usable as saved tenant colours, but they are no longer shown as a generic preset.
- No product card layout changes.
- No order/customer/push/subdomain changes.
