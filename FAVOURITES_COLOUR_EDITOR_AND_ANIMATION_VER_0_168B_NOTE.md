# Orduva Ver-0.168B — favourites colour editor and add animation

This patch extends the existing Supabase favourites feature with theme controls and add-to-cart animation support.

## Included

- Added a new **Favourites** group inside **Per-item storefront colours**
- Added editable colours for the favourites section background, border, headings, card, product title, price, Add button, remove-heart button and swipe hint
- Added the favourites group into the live preview selector
- Added a dedicated live preview for the favourite card and favourites background
- Wired the storefront favourites section and favourite cards to the new theme colours
- Added the existing flying add-to-cart animation when Add is selected from a favourite card
- Bumped the live version to Ver: 0.168B

## Not changed

- Normal product card layout
- Checkout flow
- Wildcard routing
- Public onboarding
- Owner platform access
- Admin login flow
- Supabase schema
