# Orduva Patch Ver-0.220A — Discounts & Rewards Storefront Polish

## Summary
Small UX polish patch for the Ver-0.220 discounts and rewards foundation.

## Included changes
- Discount/offers popup now uses the tenant/store colour palette more consistently.
- Reward popup now uses Silver, Gold and Platinum tier-inspired colours.
- Storefront welcome action buttons are consolidated into one compact premium row:
  - Rewards
  - Offers
  - Favourites
  - Buy again
- Favourites and Buy Again show View/Hide state text in small lettering under the icon.
- No checkout calculation changes.
- No order creation changes.
- No Stripe, Yoco, Pesapal or Daraja payment logic changes.

## SQL
No Supabase SQL required.
