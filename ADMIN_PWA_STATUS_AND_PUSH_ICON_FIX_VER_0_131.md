# Orduva Ver-0.131 — Admin PWA status bar and push icon fix

This patch supersedes the incorrectly labelled Ver-0.130D package.

## Why Ver-0.131
This is a new admin/PWA branding edit, so it uses a main version bump rather than a same-thread letter suffix.

## Changes
- Sets the admin PWA/mobile browser theme colour to the Orduva admin palette.
- Adds dedicated Orduva notification icon assets.
- Updates admin push notifications to use the proper Orduva notification icon instead of falling back to a white square.
- Updates service-worker notification defaults.
- Updates server-side push defaults.

## Not changed
- Storefront product cards.
- Add-to-cart animation.
- Checkout/order saving.
- Customer accounts.
- Netlify wildcard/domain logic.
- Platform onboarding logic.
