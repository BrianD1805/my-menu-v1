# Orduva Ver-0.168C — favourites card shadow controls

This patch refines the favourites card shadow treatment and adds controls to the tenant admin colour editor.

## Included

- Added a Favourites card shadow ON/OFF control in Per-item storefront colours
- Added a Favourites card shadow colour control
- Made the default favourites card shadow smaller and more subtle
- Reduced the internal glow overlays on favourite cards so custom card/background colours read more accurately
- Updated the live preview so the shadow toggle and colour are visible immediately

## Not changed

- Normal product card layout
- Checkout flow
- Wildcard routing
- Public onboarding
- Owner platform access
- Admin login flow
- Supabase schema
