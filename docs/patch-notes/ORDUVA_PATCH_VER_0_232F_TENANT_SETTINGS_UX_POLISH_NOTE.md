# Orduva Patch Ver-0.232F — Tenant Settings UX Polish

## Purpose
Calm down the Tenant Admin Settings page and make the settings panels easier to scan and work through.

## Changes
- Settings panels now use a calmer two-column desktop layout.
- Default panel borders are clearer and more consistent.
- Open panels now use a strong black border so the active area is obvious.
- Section titles use lighter weights instead of heavy black headings.
- Removed mixed orange/green/purple structural styling from section labels.
- Settings header/shortcut area has been toned down to neutral slate styling.
- The per-item storefront colours section remains full-width so the preview workspace still has room.

## Not changed
- No checkout logic changed.
- No payment provider logic changed.
- No product/variant logic changed.
- No invoice-payment flow changed.
- No storefront product card layout changed.
- No database/schema changes.
