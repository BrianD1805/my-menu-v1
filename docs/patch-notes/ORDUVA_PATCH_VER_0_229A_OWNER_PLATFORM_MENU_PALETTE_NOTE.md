# Orduva Patch Ver-0.229A — Owner Platform menu and palette polish

## Summary
This patch refines the Owner Platform top navigation and visual palette following review of Ver-0.229.

## Changes
- Replaced the single Menu dropdown with three separate header menu groups:
  - Core platform
  - Money and growth
  - Owner controls
- Fixed dropdown hover behaviour by keeping the hover/focus area connected between the menu button and dropdown panel.
- Removed decorative up/down glyphs from the header menu.
- Replaced the row expand icon with clear Details / Close wording.
- Rebalanced the Owner Platform colours to use black, blue #336699 and green highlights instead of the previous orange-heavy styling.
- Reduced heavy title weights so the page feels calmer and easier to scan.

## Not changed
- No storefront logic changed.
- No Tenant Admin logic changed.
- No checkout logic changed.
- No payment provider logic changed.
- No product/variant logic changed.
- No Supabase SQL required.
