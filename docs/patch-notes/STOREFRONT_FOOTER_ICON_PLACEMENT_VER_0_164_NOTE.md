# Orduva Ver-0.164 — Premium storefront footer icons and correct footer placement

## Summary

This build moves the storefront contact/social icon links into the true storefront footer content section, instead of the lower Orduva/admin utility strip.

## Changes

- Contact icons now sit inside the Storefront footer section.
- Social icons now sit inside the Storefront footer section.
- The lower Orduva/admin utility strip no longer contains phone/WhatsApp/email/social links.
- Footer text is centred.
- Footer icon buttons have a more premium rounded-card style with softer shadow, border, hover and press states.
- Product cards, checkout, admin settings and database schema were not changed.

## SQL

No Supabase SQL required.
