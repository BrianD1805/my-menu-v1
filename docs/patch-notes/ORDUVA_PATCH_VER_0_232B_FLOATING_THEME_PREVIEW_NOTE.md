# Orduva Patch Ver-0.232B — Floating desktop theme preview

## Summary

The Tenant Admin per-item storefront colour editor now uses a fixed floating desktop preview panel so the preview remains visible while editing any colour group.

## Changes

- Desktop-only floating preview panel.
- Preview remains visible while scrolling through theme colour groups.
- Added collapse/expand control for shorter screens.
- Kept suggested colours hidden by default with access below the preview.

## SQL

No Supabase SQL required.
