# Orduva Ver-0.168A — favourites visual polish

This patch polishes the customer favourites section added in Ver-0.168.

## Included

- Reduced the favourites container by roughly 20%
- Reduced favourite cards by roughly 20%
- Centred the active favourite card in the swipe area
- Changed favourite cards from `snap-start` to `snap-center`
- Hid the native horizontal scrollbar
- Added tasteful desktop arrow controls for previous/next favourite
- Kept mobile as swipe-first

## Not changed

- Normal product card layout
- Checkout flow
- Supabase schema from Ver-0.168
- Footer icon layout from Ver-0.166
- Logo palette fix from Ver-0.167
