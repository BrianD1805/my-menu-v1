# Orduva Ver-0.147 — post-onboarding success polish and client launch guidance

This build improves the client-facing success experience after automated public onboarding.

## Changes

- Bumped live version to Ver: 0.147.
- Improved the public onboarding success card so clients know their store is ready.
- Added clearer store address and owner-login confirmation.
- Added direct next-action buttons: view the new store and sign in to admin with the store prefilled.
- Added a plain-language “What to do next” guide for new clients.
- Updated the client setup guide/checklist wording returned by the public tenant creation API.
- Improved homepage onboarding copy so clients understand that guidance appears after store creation.

## Not changed

- Wildcard routing was not changed.
- Owner platform onboarding was not changed.
- Storefront product cards were not changed.
- Push notification logic was not changed.
- Supabase schema was not changed.
