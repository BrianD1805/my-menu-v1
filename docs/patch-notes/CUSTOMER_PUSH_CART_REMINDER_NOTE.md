# Orduva Ver-0.141 — Customer Push Reminder at Cart Entry

Adds a premium order-update reminder when the customer enters the cart/checkout flow.

- If order updates are already enabled, cart opens normally.
- If notifications are not enabled and the customer has not dismissed the reminder this session, a friendly popup is shown.
- Enable order updates requests browser notification permission and saves/relinks the reusable customer device subscription.
- Not now continues to cart and suppresses repeat reminders for the current session.
- Existing success-page Enable updates remains as fallback.

No Supabase SQL required.
