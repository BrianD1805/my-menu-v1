# Orduva Ver-0.133 — Product Card White Buttons With Accent Edges

This patch updates the storefront product card controls so the price box, Add button, and More button use clean white surfaces with tenant-palette accent borders.

Scope:
- Product card price box changed to white with accent edge.
- Product card Add button changed to white with accent edge and palette text.
- Product card More button changed to white with softer accent edge.
- Product details popup Add button changed to match the clean white/accent-edge style.
- Product card layout, spacing, images, add-to-cart animation, cart, checkout, orders, customer accounts, admin, and push logic were not changed.
