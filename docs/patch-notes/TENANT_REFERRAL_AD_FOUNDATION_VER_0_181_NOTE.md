# Orduva Ver-0.181 — Tenant referral advert foundation

Adds a tenant-controlled Orduva advert to the bottom storefront/footer area.

## Included

- Storefront footer advert: “Do you need a store like this?”
- Advert links to `https://www.orduva.com/start-your-store` with tenant referral parameters.
- Admin setting to show/hide the advert per tenant.
- Default is on for new and existing tenants.
- No reward calculation or referral ledger yet.

## Supabase

Run `SUPABASE_VER_0_181_TENANT_REFERRAL_AD_FOUNDATION.sql` before deploying.
