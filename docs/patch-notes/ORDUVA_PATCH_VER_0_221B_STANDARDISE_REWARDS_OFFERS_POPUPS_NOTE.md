# Orduva Patch Ver-0.221B — Standardise rewards and offers popups

This patch standardises the Rewards and Offers/Discount Codes storefront popups to follow the same modal shell used by the product More popup.

## Changes

- Rebuilt Rewards popup using the same modal structure as the storefront More popup.
- Rebuilt Offers/Discount Codes popup using the same modal structure as the storefront More popup.
- Uses the same centred overlay behaviour.
- Uses the same modal width/max-height behaviour.
- Uses the same header treatment, top accent bar and soft white/slate/emerald palette.
- Uses the same scroll-contained body area.
- Uses the same fixed footer area outside the scrolling content.
- Removes the bespoke harsh rewards/offers colour blocks from the customer-facing popups.
- Keeps the background page locked while the popups are open.

## Not changed

- No rewards calculation changes.
- No discount calculation changes.
- No checkout/payment changes.
- No product card UI changes.
- No Supabase SQL required.
