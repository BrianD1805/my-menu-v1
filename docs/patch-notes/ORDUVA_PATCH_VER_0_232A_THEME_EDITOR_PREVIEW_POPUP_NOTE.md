# Orduva Patch Ver-0.232A — Theme editor preview and popup polish

## Summary
This patch polishes the desktop Tenant Admin theme editor after Ver-0.232 introduced rewards and discount popup colour controls.

## Changes
- Makes the desktop per-item storefront colour preview sticky on the right-hand side.
- Adds Rewards popup and Discount popup preview targets so the new colour controls are visible in the preview area.
- Hides Suggested colours by default on desktop.
- Adds a Suggested colours button underneath the preview so the palette can be opened whenever needed.
- Applies the standard Orduva popup spacing approach to Tenant Admin settings modals and main product manager popups.

## SQL
No Supabase SQL required.

## Notes
No storefront checkout, payment, product, variant, invoice payment, or cart logic was changed.
