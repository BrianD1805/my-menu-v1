# Orduva Patch Ver-0.232G — Theme preview placement correction

## Purpose

Correct the Tenant Admin per-item storefront colour editor workspace so the right side stays visually clean and floating preview/suggested colour windows open beside the active colour group, not at the top of the editor.

## Changes

- Removed the right-side “Clear preview area” instruction card and left the right half as plain white space.
- Preview and Suggested Colours windows now open alongside the currently expanded colour group.
- Suggested Colours launched from a specific group now anchors beside that same group.
- The floating windows remain constrained inside the Per-item storefront colours workspace.
- No mobile behaviour changed.

## Not changed

- No checkout logic changed.
- No payment provider logic changed.
- No product/variant logic changed.
- No invoice-payment flow changed.
- No database/schema changes.
