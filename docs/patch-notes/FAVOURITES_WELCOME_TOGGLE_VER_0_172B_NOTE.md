# Orduva Ver-0.172B — welcome favourites view/hide control

Adds a small View favourites / Hide favourites control inside the storefront welcome panel for signed-in customers.

- Favourites remain hidden by default.
- Favourite IDs still load quietly in the background so product hearts can show saved state.
- The large favourites strip only appears after the customer taps View favourites.
- Signed-out customers still see no favourites area.
- No Supabase SQL required.
