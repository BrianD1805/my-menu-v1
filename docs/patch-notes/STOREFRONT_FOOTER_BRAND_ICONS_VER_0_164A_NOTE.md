# Orduva Ver-0.164A — Storefront footer brand icons

## Purpose

This patch replaces the storefront footer social placeholder letters with proper recognisable SVG icons and keeps all footer icons in the true storefront footer.

## Changes

- Bumped version to Ver: 0.164A.
- Replaced footer social placeholder text with proper icon shapes for:
  - Facebook
  - Instagram
  - TikTok
  - X
  - Website
- Kept clean UI icons for:
  - Phone
  - WhatsApp
  - Email
- Combined contact and social icons into one footer icon set.
- Desktop/tablet layout keeps the icons in one neat row where space allows.
- Mobile layout uses a tidy two-row grid style when several icons are present.
- Kept the premium rounded icon-button styling from Ver-0.164.

## Not changed

- No public onboarding or owner-platform changes.
