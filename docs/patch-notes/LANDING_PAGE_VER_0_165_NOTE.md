# Orduva Ver-0.165 — landing page logo and selling-point refresh

## Summary

This build refreshes the public Orduva landing page using the new premium Ubuntu-style Orduva logo image, removes the top navigation CTA buttons, moves those navigation actions into the footer, and simplifies the page around four stronger selling points followed by the existing black CTA block.

## Key changes

- Added the new logo image as `public/orduva-logo-ubuntu-hero.png`.
- Removed the top header action buttons from the landing page.
- Removed the hero CTA buttons from the upper page area.
- Kept the black CTA section intact and in place after the selling points.
- Added four top selling points:
  - create a colour palette from the uploaded logo
  - push notifications for new orders/customer updates
  - calm guided launch checklist
  - pricing from $5/month or $9.99/month
- Moved landing navigation actions into the footer:
  - Start your own store
  - View ZimZa Express demo
  - Admin login

## Not touched

- Storefront UI/product cards
- Checkout logic
- Tenant admin logic
- Owner platform tools
- Footer contact/social icon logic
- Supabase schema
- Public onboarding API
