# Orduva Ver-0.168D — product card heart colour controls

This patch adds product-card favourite heart colour controls to the per-item storefront colours editor and product card live preview.

## Included

- Added Product Card colour controls for:
  - Heart ticked background
  - Heart ticked colour
  - Heart unticked background
  - Heart unticked colour
- Wired the controls into the Product Card live preview.
- Wired the controls into the real storefront product-card favourite heart button.
- Preserved the existing product-card layout and only changed the heart element styling.

## Not changed

- Product card layout structure
- Favourites Supabase table/API
- Favourites carousel layout
- Checkout flow
- Wildcard routing
- Admin login flow
