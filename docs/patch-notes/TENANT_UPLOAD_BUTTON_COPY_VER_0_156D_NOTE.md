# Orduva Ver-0.156D — tenant upload button wording and autosave clarity

This same-thread polish update improves the tenant settings logo/favicon upload UX.

## Changes

- Existing uploaded logo now shows a **Change logo** action instead of the confusing native file input state.
- Existing uploaded favicon now shows a **Change favicon** action.
- The native **No file chosen** text is hidden so users do not think a previous upload failed.
- Logo/favicon upload controls now clearly state that uploads save automatically.
- The upload controls sit in a no-save sub-section so there is no separate save button for upload actions.
- Existing logo/favicon preview behaviour from Ver-0.156C remains unchanged.

## Notes

Manual URL/text edits in the branding section still use the normal save buttons. Uploading a file saves the asset URL immediately.
