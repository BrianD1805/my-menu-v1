# Orduva Ver-0.160 — unify tenant admin page backgrounds to soft grey

This build applies the same calm soft grey background treatment across the tenant admin area.

## Changed

- Bumped version to Ver: 0.160.
- Updated the shared `AdminShell` so Home, Orders, Products, Categories and Settings all use the same soft grey admin background.
- Updated the tenant admin login page to use the same soft grey background treatment.
- Removed the settings-only background switch because soft grey is now the tenant admin standard.

## Not changed

- Public landing page.
- Public client onboarding.
- Owner platform area.
- Storefront product cards.
- Checklist logic.
- Upload/storage logic.
- Supabase schema.
