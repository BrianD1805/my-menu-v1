# Orduva Patch Ver-0.223 — Storefront SEO and tracking

Adds a Tenant Settings SEO section for storefront page name, meta description, SEO keywords, canonical URL, Schema.org JSON-LD, Google Analytics / Google Ads tracking ID, and Google Tag Manager container ID.

Also fixes tenant storefront browser favicons by using the tenant favicon URL in the storefront metadata instead of the default Orduva favicon.

No checkout, storefront product card, cart or payment provider logic was changed.
