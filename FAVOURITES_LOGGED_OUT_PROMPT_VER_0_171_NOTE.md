# Orduva Ver-0.171 — logged-out favourite prompt

## Change

When a logged-out customer taps a product favourite heart, the storefront now opens a premium modal explaining that favourites require a customer account.

## UX

- No favourites strip or dark message is rendered for logged-out customers.
- Product hearts remain visible as an invitation to save favourites.
- Tapping a heart while logged out opens a polished popup with direct links to Login and Create account.
- The customer can dismiss the prompt with the close button, backdrop, or Not now button.

## Supabase

No Supabase SQL required.
