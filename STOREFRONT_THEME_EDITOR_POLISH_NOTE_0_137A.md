# Orduva Ver-0.137A — Advanced Theme Editor Polish

This patch is a same-thread polish pass for Ver-0.137.

Changes:
- Removed the Preview button from individual colour rows.
- Colour edits now automatically move the live preview to the relevant section.
- Moved the visible colour swatch directly beside the hex value to save space.
- Added a Suggested colours panel with a custom hex colour field.
- Suggested colours can be copied and pasted into any theme colour field.

No changes were made to orders, checkout, customer accounts, push notifications, onboarding, domain routing, or add-to-cart animation.
