# Orduva Ver-0.178 — Platform onboarding dashboard summary cards

Adds a simpler top summary section to `/platform/onboarding` with clickable cards for:

- Stores
- Paying clients
- Active trials
- Expiring soon
- Expired trials
- Checkout paused stores
- Needs setup

Clicking a card filters the store list below so the platform page is less overwhelming. The detailed readiness checklist remains available behind each store's Full checklist button. No Supabase SQL required.
